# ⚡ OmniCraft AI — Digital Product Studio

An all-in-one AI agent built with Streamlit and Google Gemini Pro to research, generate, format, and package digital products (E-books, Planners, Canva Blueprints, Code tools, and PDF Analyzers).

## 🚀 Features
- 🔍 **Real-time Market & Trend Research** (Google Search Grounding)
- 📖 **E-Book Studio**: Automated chapter writing + downloadable formatted PDF
- 🗓️ **Printable Planner Creator**: Time blocks, daily goals, and reflections
- 🎨 **Canva Studio**: Colors, typography, element keywords, and canvas links
- 💻 **Code Generator**: Bug-free standalone scripts and single-page web applications
- 📄 **PDF Analyzer**: Reverse engineer and extract frameworks from existing PDFs

---

## 🛠️ Local Setup

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/digital-product-agent.git](https://github.com/your-username/digital-product-agent.git)
   cd digital-product-agent
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Streamlit app:**
   ```bash
   streamlit run app.py
   ```
